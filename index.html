Abrir a Helpu neste computador

Abra INICIAR-HELPU.cmd na pasta do projeto. O portal será aberto no navegador assim que estiver pronto.

Mantenha a janela do servidor aberta durante o uso. Para encerrar, pressione Ctrl+C nessa janela.

Se o servidor já estiver rodando na porta padrão, acesse o portal.

Abrir este HTML diretamente não inicia o servidor, o cadastro ou o banco de dados. Para instalação e desenvolvimento, consulte LEIA-ME.md.
